# SET 汇报内容核对

依据本项目归档的 CVPR 2025 论文 PDF；PDF页码从1起算。用户Markdown为内容主线。

- Figure 1（PDF p1）：全特征高频遮挡对应 APvt/APt/APs 为1.14/1.08/0.96倍；仅背景高频遮挡为1.15/1.08/1.04倍。以上是相对性能，不是绝对AP点；第三组是APs，不能写成中大目标。遮挡中频时APvt为0.54倍。
- Table 5（PDF p8）：基线12.0，全图平滑12.7，HBS13.9，API13.2，联合14.2 AP。联合优于单模块，但1.9+1.2=3.1，不等于2.2，不能称近似可加或证明无冗余。正文与表的全图平滑增益存在不一致，此处采用表值并注明来源。
- Table 5：基线/HBS/API/SET训练耗时分别0.17/0.20/0.39/0.42 s/batch。API约2.29倍；SET约2.47倍（+147%）。推理路径不增加HBS/API，不等于训练零成本。表列GFLOPs与Params，未直接列峰值显存，不能把参数增幅写成实测显存增幅。
- Table 4（PDF p7）原表APt为19.6→23.3，但上标写+1.7，正文也称+1.7；算术差为3.7，原文不一致。使用总体AP 36.4→37.4作主要结论，APt若出现须并列披露矛盾，不擅自替作者纠正数值。
- Figure 5：53.99→69.93来自一个可视化示例，约+29.5%，不能冒充全测试集统计或保证所有尺度均提升。
- Figure 6：ρ=0仍可包含HBS收益，不能写成完全无增益；写成ρ>0优于无扰动设置。
- Figure 7：背景低频平均幅值0.3787→0.5205；中频0.5340→0.4249；高频0.6265→0.4518。
- Table 1：RFLA+SET 24.9对比RFLA+SR-TOD 21.8，差3.1 AP；不能混用DetectoRS+SR-TOD 24.0。
- 泛化结论限定为论文测试的检测器与数据集，不声称任意框架/数据均有效。GT质量、高频纹理误清及EdgeCrafter迁移属于讨论或待验证假设。
